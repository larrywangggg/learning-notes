# 什么是数据库

课程：COMP2400/COMP6240 – Relational Databases

## 核心概念
- Data：原始事实（如 Tom，18）
- Information：数据之间的关系（Tom 年龄是 18）
- Knowledge：信息之间的推理关系（18 岁 ⇒ 可以投票）
- Wisdom：将知识用于正确决策
- 要点：数据库关注“如何把数据组织成信息与知识”，而不是数据本身

## 数据类型与数据库定位
- 结构化数据：格式固定，典型代表是关系型数据库（表、行、列）
- 半结构化数据：有结构但不完全一致，如 XML、JSON
- 非结构化数据：无固定格式，如文本、图片、视频
- 课程重点：结构化数据 + 关系型数据库

## 为什么学数据库
- 支持数据管理与分析
- 支撑现实系统：个性化医疗、知识图谱、政府系统等
- 趋势变化：small data → big data，data → knowledge

## 数据库研究的重要性
- 图灵奖得主：Bachman、Codd、Gray、Stonebraker
- 说明：数据库是计算机科学的重要理论基础之一

## 数据伦理
- 隐私是一项人权
- 关键问题：谁拥有数据、谁可以收集、如何被保护
- 风险场景：监控、误导、政治压迫、暴力、勒索
- 自检：Is this the right thing to be doing?
