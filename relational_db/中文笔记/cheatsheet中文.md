# 关系数据库速查表

考试级核心概念速记。

---

## 核心概念
- **数据库**：相关数据的集合
- **DBMS**：创建与管理数据库的软件
- **数据库系统**：DBMS + 数据库（信息系统的一部分）

### 优势
- 降低冗余
- 完整性与安全性
- 并发控制
- 备份/恢复
- 数据独立性

---

## ANSI/SPARC 三层结构
- **外部模式**：用户/应用视角（数据子集）
- **概念模式**：全局逻辑视角（实体与关系）
- **内部模式**：物理存储视角

---

## 完整性约束
- **域约束**：值必须来自属性域（INT、VARCHAR、NOT NULL 等）
- **键约束**：唯一性（超键/候选键/主键）
- **实体完整性**：主键不可为 NULL
- **参照完整性**：外键必须匹配被引用主键

---

## 键
- **超键**：唯一决定所有属性
- **候选键**：最小超键
- **主键**：选定的候选键

---

## ER 模型（Week 4）
- **实体 / 属性 / 联系**
- **弱实体**：自身属性不足以成键，依赖识别实体与识别关系
- **EER**：加入 ISA 等扩展

---

## 函数依赖（Week 5）
- **FD**：X → Y（X 相同则 Y 相同）
- **平凡 FD**：Y ⊆ X
- **闭包**：X⁺ 为 X 能决定的全部属性
- **主属性**：出现在某个候选键中的属性

---

## 规范化（Week 6）
- **目标**：消除冗余与异常
- **BCNF**：任意非平凡 X → A，X 必须是超键
- **3NF**：任意非平凡 X → A，X 是超键或 A 为主属性

### BCNF 两性质
- **无损连接**：连接后无伪元组
- **依赖保持**：分解后仍可检查 FD
- BCNF 不一定能同时满足两者

### 最小覆盖（用于 3NF）
1. RHS 单属性
2. 去掉 LHS 冗余属性
3. 删除冗余 FD

---

## 关系代数（Week 7）
- **过程式语言**；满足闭包与可组合性
- **基本算子**：σ（选择）、π（投影）、ρ（重命名）、∪、−、×
- **选择可交换**：σϕ1(σϕ2(R)) = σϕ1∧ϕ2(R)
- **投影不交换**（可能丢列）

### RA ↔ SQL
- σϕ(R) → `SELECT DISTINCT * FROM R WHERE ϕ`
- πA(R) → `SELECT DISTINCT A FROM R`
- R1 − R2 → `SELECT * FROM R1 EXCEPT SELECT * FROM R2`
- R1 ⋈ϕ R2 → `SELECT DISTINCT * FROM R1 JOIN R2 ON ϕ`

---

## 查询处理与优化（Week 8）
### DBMS 流程
- **Parser/Translator** → RA
- **Optimizer** → 执行计划
- **Evaluation engine** → 执行

### 优化方法
- **语义优化**：利用约束简化
- **规则优化**：下推 σ/π，重排 join
- **代价优化**：估算 I/O 与中间结果大小

---

## 数据库安全（Week 9）
- **CIA**：机密性 / 完整性 / 可用性

### 访问控制
- **DAC**：用户授权，灵活但泄露风险高
- **MAC**：集中控制
- **RBAC**：角色管理

### GRANT / REVOKE
- `WITH GRANT OPTION` 可再授权
- `RESTRICT`：阻止撤销（若仍有依赖）
- `CASCADE`：级联撤销

---

## 事务（Week 10）
- **ACID**：原子性、一致性、隔离性、持久性
- **WAL**：先写日志后写数据
- **2PL**：先加锁后释放 → 可串行化

### 并发异常
- 丢失更新、脏读、不可重复读、幻读

### 隔离级别
| 级别 | 脏读 | 不可重复读 | 幻读 |
| --- | --- | --- | --- |
| READ UNCOMMITTED | ✔ | ✔ | ✔ |
| READ COMMITTED | ✘ | ✔ | ✔ |
| REPEATABLE READ | ✘ | ✘ | ✔ |
| SERIALIZABLE | ✘ | ✘ | ✘ |

---

## NoSQL（Week 11）
- **类型**：键值、列族、文档、图
- **BASE**：基本可用、软状态、最终一致
- **适用**：高并发、灵活结构、深层关系

---

- Join = × + σ
- SQL 表默认 bag 语义；RA 是 set 语义
- 隔离级别越高越安全但越慢
