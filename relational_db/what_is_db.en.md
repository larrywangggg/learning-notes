# What Is a Database

Course: COMP2400/COMP6240 - Relational Databases

## Core Concepts
- Data: raw facts (e.g., Tom, 18)
- Information: relationships between data (Tom is 18)
- Knowledge: inferences from information (18 -> can vote)
- Wisdom: using knowledge to make the right decisions
- Key point: databases focus on organizing data into information and knowledge, not on data alone

## Data Types and Where Databases Fit
- Structured data: fixed format, typical of relational databases (tables, rows, columns)
- Semi-structured data: some structure but not uniform, e.g., XML, JSON
- Unstructured data: no fixed format, e.g., text, images, video
- Course focus: structured data + relational databases

## Why Study Databases
- Enable data management and analysis
- Power real systems: personalized medicine, knowledge graphs, government systems
- Trend shifts: small data -> big data, data -> knowledge

## Why Database Research Matters
- Turing Award winners: Bachman, Codd, Gray, Stonebraker
- Takeaway: databases are a core CS theory area, not just engineering details

## Data Ethics
- Privacy is a human right
- Key questions: who owns data, who can collect it, how it is protected
- Risk scenarios: surveillance, manipulation, political oppression, violence, extortion
- Self-check: Is this the right thing to be doing?
