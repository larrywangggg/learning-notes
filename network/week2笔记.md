# Network Week 2 笔记

**本周主题：** Physical Media（物理传输介质）— Copper → Fibre → Wireless → Last Mile

> 核心思想：网络性能最终由物理介质决定。选择介质就是在**性能 / 成本 / 部署难度 / 维护 / 覆盖范围**之间做取舍。

---

## 一、铜缆（Copper）

### 1.1 为什么用铜

| 优点 | 说明 |
|------|------|
| Ubiquity | 世界各地已大规模铺设 |
| 导电性好 | 传输电信号效率高 |
| 成本低 | 加工简单，原材料便宜 |
| 柔软 | 容易弯曲布线 |
| 技术成熟 | 100+ 年使用经验 |

理论上铝、钢、陶瓷甚至湿绳子都能传信号——通信的本质是信号传播，不是"必须铜线"。

### 1.2 铜缆的物理问题

**(a) 电阻损耗（Attenuation / Insertion Loss）**

$$R = \rho \frac{L}{A}$$

线越长、越细，电阻越大，信号衰减越多。

**(b) 趋肤效应（Skin Effect）**

高频电流只在导体**表面**流动，等效截面积缩小，电阻上升。频率越高，衰减越严重。这是 DSL 高频段表现差的根本原因。

**(c) 天线效应（Antenna Effect）**

一根直导线本质上就是天线：
- 接收外部电磁干扰（EMI/RFI）
- 向外泄漏自己的信号
- 与相邻导线发生 **crosstalk（串扰）**

所以铜线问题常常不是"线断了"，而是"线在收别人的信号"。

### 1.3 电力线通信（PLC, Power Line Communication）

在现有电力线上叠加数据信号：

| 场景 | 速度 | 距离 |
|------|------|------|
| ISP → 家庭 | < 1 Mbps | km 级 |
| 楼内 Powerline Adapter | ~100 Mbps | 几十米 |

> **例子：** 家用 Powerline Adapter 插在两个插座上，直接用房子的电线当网线——不用额外布线就能把信号从路由器延伸到另一个房间。

### 1.4 同轴电缆（Coaxial Cable）

结构（由内到外）：
```
中心导体（Signal）→ 绝缘层（Dielectric）→ 屏蔽层（Shield）→ 外护套（Jacket）
```

**优点：** 屏蔽层阻隔外部干扰，信号质量好  
**缺点：** 每根只有一个信号通道，不适合全双工；成本较高

常见型号：

| 型号 | 用途 |
|------|------|
| RG-58 | 早期 10BASE-2 Ethernet |
| RG-6 | 有线电视（Cable TV）|
| RG-59 | CCTV 监控 |

### 1.5 空分复用（Spatial Division Multiplexing）

多根线并行传输，每根线负责一路数据：
- 优点：可实现 **Full Duplex**（发送/接收用不同线），带宽叠加
- 缺点：相邻线越多，串扰越严重

> **例子：** HDMI 内部有多对差分数据线 + 时钟线；USB 3.0 有 5 对以上的导线并行工作。

### 1.6 差分信号（Differential Signalling）

**核心思想：** 用两根线传同一信号的正/反相，接收端做差值。

```
wire1: +V + noise
wire2: -V + noise
差值: (+V + noise) - (-V + noise) = 2V   ← 噪声抵消
```

只要噪声同时作用在两根线上，就会被自动抵消。

### 1.7 双绞线（Twisted Pair）

噪声通常来自某一个方向——若两根线平行，离噪声近的那根受影响更大。

**解决方案：** 把两根线绞在一起（twisting）→ 两根线轮流靠近/远离噪声源，平均下来干扰几乎相等 → 差分相减后噪声几乎消除。

```
/\/\/\/\/\/\/\/\
```

> **例子：** 网线中每对线的绞距（每米扭转圈数）都不同，Cat5e 和 Cat6 的绞距参数不同，这正是高类别网线抗串扰能力更强的原因之一。

**UTP（Unshielded Twisted Pair）：** 无屏蔽双绞线，现代网络最常见介质。

### 1.8 网线类别（Category）

| 类别 | 带宽 | 最大速率 | 典型应用 |
|------|------|----------|----------|
| Cat 3 | 16 MHz | 10–100 Mbps | 旧式电话/Ethernet |
| Cat 5e | 100 MHz | 1 Gbps | 主流家庭/办公 |
| Cat 6 | 250 MHz | 10 Gbps（短距离）| 数据中心/高性能 |
| Cat 6A | 500 MHz | 10 Gbps（100m）| 企业网络 |
| Cat 7 | 600 MHz | 10 Gbps | 数据中心 |
| Cat 8 | 2000 MHz | 40 Gbps | 短距离高速互联 |

**规律：** 类别越高 → 带宽越大 → 速率越高，但价格更贵、线更硬、施工更麻烦。

屏蔽版本命名规则：

| 符号 | 含义 |
|------|------|
| U | 无屏蔽 |
| F | Foil（金属箔）|
| S | Braided Shield（编织网）|

例如 `S/FTP` = 外层编织屏蔽 + 每对线都有 foil 屏蔽，性能最好但最贵最硬。

### 1.9 传播延迟问题

电在铜线中传播速度约为光速的 2/3。高速传输时：
- 不同线对长度不一致 → **skew（时序偏差）** → 接收端无法正确重建信号
- 还会引发 **propagation delay** 和 **collision 问题**

## 二、DSL（Digital Subscriber Line）

### 2.1 基本概念

DSL = 在原有 **PSTN（Public Switched Telephone Network）** 电话铜线上传输互联网数据，无需重新铺线。

```
电话交换局（Exchange）
       │
       │ 铜线（原电话线）
       │
     你家
```

标准由 **ITU（International Telecommunication Union）** 制定，标准编号如 G.992、G.993 等。

### 2.2 DSL 类型对比

| 类型 | 下行 | 上行 | 距离限制 | 特点 |
|------|------|------|----------|------|
| ADSL | 10 Mbps | 1 Mbps | ~4 km | 非对称，家庭主流 |
| ADSL2 | 12 Mbps | 3.5 Mbps | ~4 km | 改进版 |
| ADSL2+ | 24 Mbps | 3.5 Mbps | ~3 km | 最常见旧宽带 |
| VDSL | 52 Mbps | 16 Mbps | ~1 km | 速度快但距离短 |
| VDSL2 | 200 Mbps | 100 Mbps | ~500 m | 需光纤配合（FTTN）|
| G.fast | 1 Gbps | 500 Mbps | ~100 m | 极短距离 |
| XG.fast | 10 Gbps | — | ~130 m | 实验性 |

**核心规律：** 铜线长度越短，可用频段越高，速率越快。

### 2.3 为什么是 Asymmetric（非对称）

- **商业原因：** 家庭用户下载远多于上传
- **技术原因：** 去你家的那对线基本只有你在用（上行），但进交换局的那束线是很多用户共享的（下行），交换局发射功率更强，下行更有优势

### 2.4 DSL 的工作原理：DMT 多载波

DSL 使用 **DMT（Discrete Multi-Tone）** 技术，将频谱切成大量小子信道：

- 每个子信道宽度约 **4.3125 kHz**（简称 4 kHz）
- 每个子信道用 **QAM** 调制（振幅 + 相位同时编码）
- 根据该子信道的信噪比（SNR）自适应调整每个符号携带 2–16 bit
- 所有子信道并行工作，合计形成总速率

**频谱划分（以 ADSL 为例）：**
```
|  POTS   |  上行  |        下行         |
0      4kHz  138kHz               ~1.1 MHz
```

- POTS（Plain Old Telephone Service）：0–4 kHz，传统语音
- 上行：25 kHz–138 kHz
- 下行：138 kHz–几 MHz

**为什么子信道约 4 kHz？**
1. 与语音 4 kHz 带宽兼容，划分方便
2. 可对每个子信道单独自适应（噪声大就降速或关闭）
3. 与 FFT/DSP 计算匹配，硬件实现高效（symbol rate ≈ 4000 sym/s）

> **例子：** ADSL 频段约 1.1 MHz，子信道宽 4.3125 kHz → 约 256 个 subcarrier 同时并行传输。某个子信道对应 AM 电台频率时，SNR 被打坏，modem 自动把那个子信道降速或关闭（称为 notch）。

**网络设备：**
- 家庭侧：**DSL modem**（数字信号 ↔ 电话线模拟信号）
- 交换局侧：**DSLAM（DSL Access Multiplexer）**，汇聚大量家庭 DSL 线路后接入光纤骨干

### 2.5 铜线频率限制（Copper Limit）

| 技术 | 频率范围 | 典型距离 |
|------|----------|----------|
| ADSL | ~1 MHz | 4 km |
| ADSL2+ | ~2.2 MHz | 3 km |
| VDSL2 | ~12 MHz | 500 m |
| G.fast | ~100 MHz | 100 m |

**根本原因：** 铜线等效于电阻 + 电感 + 电容的组合，天然构成低通滤波器：
- 趋肤效应 → 高频电阻增大
- 电容 → 高频信号漏电
- 电感 → 高频阻抗增大

结论：频率越高，衰减越严重，可用距离越短。这是 DSL 性能的根本物理瓶颈。

### 2.6 DSL 升级技术

| 技术 | 作用 |
|------|------|
| G.inp | 错误恢复机制，减少外部噪声影响 |
| G.vector | 预测并抵消多对铜线之间的串扰，提升速率至 ~100 Mbps@500m |
| G.fast | 使用 ~100 MHz 频段，1 Gbps，但距离仅 ~100 m |

## 三、光纤（Fibre）

### 3.1 光纤的优势

| 对比项 | 铜线 | 光纤 |
|--------|------|------|
| 频率范围 | 几百 MHz | THz 级 |
| 典型带宽 | Gbps | Tbps |
| 抗电磁干扰 | 差 | 完全免疫 |
| 传输距离 | km 级（DSL）| 数十至数千 km |
| 衰减 | 较大 | 极低（约 0.2 dB/km）|

### 3.2 工作原理：全内反射（Total Internal Reflection）

**折射率（Refractive Index）：**
$$n = \frac{c}{v}$$

- $c$ = 真空光速 ≈ 300,000 km/s
- $v$ = 光在材料中的速度

材料折射率越高，光在其中传播越慢。光从高折射率材料进入低折射率材料时，如果入射角超过**临界角**，光会被**完全反射**，不再折射出去。

**光纤结构：**
```
外护套（Jacket）— 机械保护
    包层（Cladding, n₂）— 低折射率，将光反射回去
        纤芯（Core, n₁）— 高折射率（n₁ > n₂），光传输通道
```

光在纤芯中发生全内反射，沿光纤传播：
```
/\/\/\/\/\/\/\/\/\/\/\
```

### 3.3 模式（Mode）与模态失真

**每一条传播路径 = 一个 mode。** 多个路径长度不同，到达时间不同，导致脉冲展宽：

```
输入：│█│  →  输出：│████│
```

这叫 **Modal Distortion（模态失真）**，会导致信号混叠、速率下降。

### 3.4 光纤类型对比

| 类型 | 纤芯直径 | 特点 | 用途 |
|------|----------|------|------|
| Step-index multimode | 50–100 μm | 多路径，模态失真严重 | 短距离（已少用）|
| Graded-index multimode | 50–62.5 μm | 折射率渐变，失真减少 | 数据中心（~300 m–2 km）|
| Single-mode | ~9 μm | 只允许一条路径，几乎无失真 | 骨干网、城际、海底（50–100+ km）|

**Graded-Index 的原理：** 纤芯中心折射率高，边缘折射率低。弯曲路径的光在外侧折射率低的区域传播更快，路径更长但速度也更快，最终与直线路径同时到达，模态失真大幅减少。

**Single-mode 为什么贵：**
- 纤芯极细（~9 μm，约头发丝直径的 1/10）→ 需要激光光源（非 LED）
- 接续精度要求极高
- 光纤制造工艺更复杂

### 3.5 光纤接续（Splicing）

**熔接（Fusion Splicing）：** 将两根光纤端面对准，用电弧加热熔化，永久焊接在一起。

- 接头损耗极低（约 0.02 dB）
- 完成后套热缩套管保护
- 与整根光纤几乎无异

**关键区别：**
- **Splice（熔接）：** 路径分叉点，光纤物理连续，无插头，无需供电
- **Termination（终端接头）：** 光纤末端安装连接器（如 ONT 处），可插拔

路口处仅需 splice，不需要每个分叉点都做 termination，大幅降低成本。

### 3.6 光纤的信号衰减与中继

**自然传输距离：**
- Multimode fibre（MMF）：约 1–2 km
- Single-mode fibre（SMF）：约 50–100 km

**衰减来源：** 瑞利散射（Rayleigh scattering）、材料吸收、接头损耗、弯曲损耗。光纤有几个低损耗"传输窗口"，常用波长：1310 nm 和 1550 nm。

**延伸距离的方法：**

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| Regenerate / OEO | 光→电→解码→重编码→光 | 信号完全恢复，无噪声积累 | 贵，复杂，需供电 |
| Amplify（EDFA）| 直接放大光信号 | 便宜，无需光电转换 | 同时放大噪声 |

**EDFA（Erbium Doped Fibre Amplifier，铒掺杂光纤放大器）：** 在光纤中掺入铒元素，用泵浦激光激发铒原子，信号光经过时被直接放大。每隔约 80–100 km 放置一个。

> **例子：** 跨太平洋海底光缆（日本→美国，约 9,000 km）内有约 80–100 个光放大器，全部位于海底，几十年基本不维修。澳大利亚曾做实验：信号从 Melbourne 出发，绕经 Sydney 和 Perth 再回到 Melbourne，总距离 10,358 km，仍能以 100 Gbps 传输。

### 3.7 光纤容量的来源

**WDM（Wavelength Division Multiplexing，波分复用）：** 在同一根光纤中同时发送多种不同波长（颜色）的光，每个波长是一个独立数据通道。

```
λ₁ (1530nm) ──┐
λ₂ (1534nm) ──┤
λ₃ (1538nm) ──┼──→ 单根光纤 ──→ ...
...           ──┤
λₙ            ──┘
```

- **CWDM（粗波分复用）：** 约 8–18 个波长
- **DWDM（密集波分复用）：** 可达 80–160 个波长，每波长 100 Gbps → 单纤 **16 Tbps**

**其他提升容量的技术：**
- 多芯光纤（Multi-core fibre）：一根光纤内含 7/19 个独立纤芯
- 预失真补偿（Pre-distortion）：发射端预先扭曲信号，光纤传输后恢复正常

**实验室记录：**
- 2012：1 Pb/s over 50 km
- 2017：10.2 Pb/s over 11 km
- 2021：319 Tb/s over 2,900 km（实用长距离）

2020 年全球互联网流量约 375,000 PB/月 ≈ **1.4 Pb/s**——理论上可以放进一根光纤。

## 四、无线（Wireless）

### 4.1 无线 ≠ Wi-Fi

无线通信覆盖整个电磁频谱：

| 技术 | 频率 | 特点 |
|------|------|------|
| ELF（极低频）| 3–30 Hz | 潜艇通信 |
| AM 广播 | ~1 MHz | 远距离，音质差 |
| FM 广播 | 88–108 MHz | 城市覆盖，音质好 |
| 电视广播 | 100–800 MHz | — |
| Wi-Fi | 2.4/5/6 GHz | 短距高速 |
| 毫米波（mmWave）| 30–300 GHz | 5G 高频段 |

Free Space Optics 也属于无线：Heliograph（镜子反光）、Photophone（贝尔发明）、激光通信（Gbps 级）、LiFi（LED 闪烁传数据）、红外遥控。

### 4.2 AM 与 FM 调制对比

| 项目 | AM | FM |
|------|----|----|
| 调制方式 | 改变振幅（Amplitude）| 改变频率（Frequency）|
| 频率范围 | 535 kHz–1,605 kHz | 88 MHz–108 MHz |
| 覆盖距离 | 很远（地波数百 km，天波可达千 km）| 较近（30–100 km）|
| 抗干扰 | 差（噪声改变振幅）| 好（噪声不改变频率）|
| 音质 | 差（带宽约 4–5 kHz）| 好（带宽约 15 kHz）|

**AM 为什么传播远：** 使用中波，白天地波传播几百 km；夜间被电离层反射（Skywave），可达数千 km。

**与 DSL 的关系：** AM 广播频段（0.5–1.7 MHz）与 DSL 频段重叠。电话铜线（几百米至几公里长）相当于巨大天线，会接收 AM 信号，导致对应子信道 SNR 下降，形成频谱"notch"。

### 4.3 频率 / 距离 / 速率的核心 Trade-off

| | 低频 | 高频 |
|--|------|------|
| 传播距离 | 远 | 近 |
| 穿墙能力 | 强（绕射好）| 差 |
| 数据速率 | 低 | 高 |
| 天线尺寸 | 大 | 小 |
| 功耗 | 低 | 高 |

不同无线技术的定位：

| 技术 | 速率 | 距离 | 典型用途 |
|------|------|------|----------|
| LoRa / SigFox | 几 kbps | 10–50 km | IoT 传感器 |
| Bluetooth | 1–3 Mbps | 10 m | 短距外设 |
| ZigBee / Z-Wave | 几百 kbps | 几十 m | 智能家居 |
| Wi-Fi | 几百 Mbps–几 Gbps | 几十 m | 室内接入 |
| 4G/5G | 几十–几百 Mbps | 数 km | 移动接入 |
| 5G mmWave | 数 Gbps | 几十 m | 热点区域 |

**核心结论：** 长距离、高速率、低功耗——最多只能同时实现两个。

### 4.4 无线传播的物理影响因素

- **Absorption（吸收）：** 气体、水汽、植被、建筑材料吸收信号能量
- **Noise：** 其他无线设备的干扰
- **Distance：** 功率按距离平方衰减（$P \propto 1/d^2$）
- **Reflection / Refraction / Diffraction：** 建筑反射、地形绕射、湿度折射
- **Multipath：** 同一信号从不同路径到达接收端，叠加后可能相消（fading）

**大气波导（Atmospheric Ducting）：** 海面高湿度使近地面折射率高，上方空气折射率低，形成类似光纤的"波导结构"，信号被困在两层之间传播，可超过 100–500 km。这解释了为什么有时能收到很远的 FM 电台。

### 4.5 无线作为 Shared Medium 的安全含义

无线是**广播介质**：
- 一旦发出，信号会向四周传播
- 任何人都可以监听，且发送方无法感知
- 有线网络被物理接入限制；无线默认比有线更"暴露"

### 4.6 天线

天线尺寸通常与波长同量级（约 λ/4 或 λ/2）：
- AM 广播（λ ≈ 300 m）→ 广播塔几十米高
- Wi-Fi（λ ≈ 6 cm）→ 天线可以塞进手机

方向性：Omnidirectional（全向）vs. Directional（定向，如碟形天线）

### 4.7 Link Budget（链路预算）

无线系统设计核心：

$$\text{接收功率} = \text{发射功率} + \text{天线增益} - \text{自由空间损耗} - \text{环境损耗}$$

接收功率必须高于接收机灵敏度（Receive Sensitivity），才能可靠解码。

### 4.8 蜂窝网络与切换（Handover）

手机同时监测多个基站信号强度，移动过程中自动切换到更强的基站（**Handover / Handshake**），保持会话不中断。

- 不同速度场景有不同要求（步行 vs. 高铁）
- Wi-Fi 校园漫游是相同逻辑

现代手机集成多套无线系统（约 2–3 组射频芯片）：

| 系统 | 频率 |
|------|------|
| 4G LTE | 800–2200 MHz |
| Wi-Fi | 2.4/5/6 GHz |
| Bluetooth | 2.4 GHz |
| GPS | 1200–1600 MHz |
| FM Radio | 约 100 MHz |

### 4.9 卫星通信

| 类型 | 轨道高度 | 延迟 | 特点 |
|------|----------|------|------|
| GEO（地球同步轨道）| 36,000 km | ~250 ms RTT | 固定覆盖广，延迟高 |
| MEO（中地球轨道）| 2,000–20,000 km | 中等 | GPS 常用 |
| LEO（近地轨道）| 400–1,200 km | ~20–40 ms | 低延迟，需大量卫星 |

**Starlink（LEO 星座）关键技术：**
- **Phased Array 天线：** 用户端不需要机械转动，通过电子方式虚拟转向，实时追踪过顶卫星
- **星间链路（Inter-satellite Links / Space Lasers）：** 卫星之间直接激光通信，减少对地面站的依赖，实现跨洋传输
- **延迟优势：** 真空中光速比光纤快约 50%，某些极端延迟敏感场景下走 LEO 可能比走海底光缆更快
- **Direct-to-Cell：** 新一代可直接用手机（无额外天线）接入卫星，发展中

**高空中继层（无人机/气球）：** Google Loon 气球、Facebook 太阳能无人机、系留气球，作为"临时基站"，适合灾区/偏远地区临时覆盖。

### 4.10 频谱监管

不能随便挑频率发射。各国有频谱管理机构（澳洲：ACMA）管理：
- 频段分配（哪段给什么用途）
- 功率上限
- 辐射/泄漏要求
- 许可证制度（部分频段需要 licence，部分如 ISM 频段开放使用）

无线设计有三层约束：**物理（Physics）→ 工程（Engineering）→ 监管（Regulation）**

## 五、Last Mile 与 FTTx

### 5.1 什么是 Last Mile

**Last Mile（最后一公里）：** 从骨干网 / 交换局（Exchange）到最终用户（住宅/办公室）的最后一段接入网络。

**为什么 Last Mile 难：**
- 骨干网：节点少，可集中投资高性能光纤
- Last Mile：端点数量巨大（澳洲约 1,000–1,100 万个）、地理分散、每户收益有限、土建/维护/供电成本高

**本质不是"技术上能不能"，而是"规模化后值不值得、谁来付钱、如何维护"。**

### 5.2 覆盖面积的几何优势

铜线 DSL 的最大距离约 4 km：
- 覆盖面积 = π × 4² ≈ 50 km²

光纤可轻松延伸 40+ km：
- 覆盖面积 = π × 40² ≈ 5,000 km²

光纤让一个交换节点的服务半径扩大 10 倍 → **覆盖面积扩大 100 倍** → 大幅减少所需节点数量。

### 5.3 FTTx 各方案详解

FTTx = **Fibre To The X**，X 代表光纤延伸到的位置。

---

#### FTTP / FTTH（Fibre to the Premises / Home）

光纤直接铺到用户门口/室内。

```
骨干网 ──光纤──→ OLT ──光纤──→ Splitter ──光纤──→ ONT ──→ 用户设备
```

| 指标 | 说明 |
|------|------|
| 典型速率 | 100 Mbps–10 Gbps（取决于服务商） |
| 铜线段 | 无（全光纤）|
| 供电需求 | ONT 在用户侧供电 |
| 维护难度 | 相对简单（passive 中间段）|
| 成本 | 最高（到户施工）|

**优点：** 性能最好，升级空间最大，不受铜线距离限制，未来导向最强。  
**缺点：** 初期建设成本最高，全量替换旧铜网代价巨大，需入户施工。

> **例子：** 澳洲 NBN FTTP 升级方案、新建住宅区标配。用户端装 **ONT（Optical Network Terminal）**，将光信号转为以太网信号接路由器。

---

#### FTTN（Fibre to the Node）

光纤到街边"节点柜"（街边绿柜子），再用原有铜线到各家。

```
骨干网 ──光纤──→ Node（街边柜）──铜线（数百米）──→ 用户家
```

| 指标 | 说明 |
|------|------|
| 铜线段 | 100–600 m（大幅短于传统 DSL 的 4 km）|
| 典型速率 | 25–100 Mbps（取决于铜线段长度）|
| 节点设备 | Active（需供电、需维护）|
| 成本 | 中等（复用旧铜线）|

**优点：** 大幅缩短铜线段（4 km → 约 300–500 m），性能比纯 DSL 提升显著；复用已有铜线基础设施，建设快。  
**缺点：** 仍受铜线段长度影响（越远越慢）；节点柜是 active 设备，需供电和定期维护；性能天花板低于 FTTP。

> **例子：** 澳洲 NBN 初期大量部署 FTTN，是速度和成本的折中方案。用户家中仍需 DSL modem，速率因到节点柜的铜线距离而异，近的可达 100 Mbps，远的可能只有 25 Mbps。

---

#### FTTC（Fibre to the Curb / Kerb）

光纤延伸到路边（距住宅约 10–100 m 处），每户门外装一个小型配线盒（DPU），仅剩室内段用铜线。

```
骨干网 ──光纤──→ DPU（路边盒）──极短铜线──→ 用户家
```

| 指标 | 说明 |
|------|------|
| 铜线段 | 约 10–100 m |
| 典型速率 | 100–250 Mbps |
| 节点设备 | Active（DPU 需供电，通常由用户 modem 反向供电） |
| 成本 | 中高 |

**优点：** 铜线段极短，性能接近 FTTP；无需进入用户室内。  
**缺点：** 每户附近都需要 DPU（active 设备）；供电和责任边界复杂（通常由用户端 modem 通过铜线反向供电给 DPU）；部件多，维护更繁琐。

> **例子：** 澳洲 NBN FTTC 方案，使用 VDSL2 或 G.fast 技术在极短铜线段上达到 100–250 Mbps。用户需安装支持反向供电（Reverse Power Feed）的 NCD（Network Connection Device）设备。

---

#### FTTB（Fibre to the Building / Basement）

光纤到楼宇/大楼地下室或配线间，楼内各户通过内部铜线或以太网连接。

```
骨干网 ──光纤──→ 楼宇配线间 ──楼内铜线/网线──→ 各用户房间
```

| 指标 | 说明 |
|------|------|
| 铜线段 | 楼内走线，通常 < 100 m |
| 典型速率 | 100 Mbps–1 Gbps（楼内用 VDSL2 或以太网）|
| 适用场景 | 公寓楼、办公楼 |
| 成本 | 较低（只需光纤到楼，楼内复用原有线路）|

**优点：** 适合高密度住宅（公寓楼），光纤只需铺到楼，楼内复用原有电话线/以太网，成本极低。  
**缺点：** 楼内铜线老化可能影响性能；楼宇配线间需维护；共享楼内带宽。

> **例子：** 澳洲 NBN FTTB 方案专为公寓楼设计。光纤引入地下室，再用 VDSL2 通过楼内原有电话线到各户，速率通常可达 100 Mbps。此方案避免了在每栋公寓楼内重新布设光纤的巨大成本。

---

#### HFC（Hybrid Fibre Coaxial）

光纤到街区/小区节点，再用同轴电缆（coax）连接多户住宅。本质是复用已有的有线电视（Cable TV）网络基础设施。

```
骨干网 ──光纤──→ Optical Node ──同轴电缆──→ 几十户住宅（共享）
```

| 指标 | 说明 |
|------|------|
| 典型速率 | 下行 100 Mbps–1 Gbps，上行相对较低 |
| 共享结构 | 一段 coax 连接多户，高峰期速率下降 |
| 成本 | 较低（复用 Cable TV 基础设施）|
| 技术标准 | DOCSIS（Data Over Cable Service Interface Specification）|

**优点：** 同轴电缆性能优于普通铜线；大量复用已有 Cable TV 网络，建设成本低；部署快。  
**缺点：** **Shared medium**——多户共享一段 coax，高峰期（晚上 8–10 点）速率明显下降；上行带宽通常较窄；老旧 HFC 系统维护复杂。

> **例子：** 澳洲 NBN HFC 方案在悉尼、墨尔本等已有 Foxtel 有线电视网络的区域大量使用。一个 Optical Node 通常服务约 500 户，通过同轴电缆分发。DOCSIS 3.1 标准理论下行可达 10 Gbps，但实际受共享用户数影响。

---

#### PON / GPON（Passive Optical Network / Gigabit PON）

光纤接入的"高效共享"方案：在光路中用 **无源分光器（Passive Splitter）** 将光信号分配给多户，中间无需供电设备。

```
OLT ──单根光纤──→ Passive Splitter（1:32/1:64）──→ 各户 ONT
       （局端）                                        （用户端）
```

| 组件 | 全称 | 位置 |
|------|------|------|
| OLT | Optical Line Terminal | 交换局 |
| Splitter | Passive Optical Splitter | 路边/楼内 |
| ONT/ONU | Optical Network Terminal/Unit | 用户家 |

| 技术标准 | 典型速率 | 分光比 |
|----------|----------|--------|
| GPON | 2.5 Gbps 下行 / 1.25 Gbps 上行（共享）| 最多 1:64 |
| XGS-PON | 10 Gbps 下行 / 10 Gbps 上行 | 最多 1:128 |
| NG-PON2 | 40 Gbps+ | — |

**核心思想：** 用 passive 分光器取代 active 交换设备，减少中间需要供电和维护的节点，降低成本。

**区分上下行的方法：** OLT 向下广播，ONT 只接收属于自己的数据（通过时隙或波长区分）；上行则由 OLT 集中调度，各 ONT 在指定时隙发送（TDMA），避免碰撞。

**优点：** 中间段完全 passive，无需供电，维护极少；光纤利用率高（多户共享一段主干光纤）；成本效益好，适合大规模 FTTP 部署。  
**缺点：** 仍有共享结构（多户共享总带宽）；设计和故障排查比点对点光纤复杂。

> **例子：** 澳洲 NBN FTTP 方案采用 GPON，一根主干光纤最多分到 32 户。Splitter 通常位于路边配线箱，完全无源，无需供电，极少维护。用户侧的 ONT 由 NBN 提供，外观类似小路由器，接电后接路由器即可上网。

---

### 5.4 Fixed Wireless Access（固定无线接入）

光纤/铜线铺设不划算时，使用定向无线链路连接用户。

```
基站（连接光纤 backhaul）──无线──→ 用户家天线 ──→ 用户路由器
```

**适用场景：** 人口密度不足以支撑 fibre 铺设成本，但又不需要卫星的偏远/农村区域。

**优点：** 不需要挖掘到每户；上线快；覆盖范围较灵活。  
**缺点：** 需要在用户屋顶/外墙安装天线；受地形、天气、建筑遮挡影响；容量受基站用户数影响；塔台本身需要光纤 backhaul 支持。

> **例子：** 澳洲 NBN Fixed Wireless 方案覆盖约 3% 的地理面积，主要是郊区和农村。基站通常在山顶或高处，用户端安装小型定向天线指向基站。实际速率约 25–75 Mbps，延迟约 15–30 ms。

---

### 5.5 FTTx 方案综合对比

| 方案 | 铜线段 | 典型速率 | 成本 | 适用场景 |
|------|--------|----------|------|----------|
| FTTP/FTTH | 无 | 100 Mbps–10 Gbps | 最高 | 新建区域、长期投资 |
| FTTB | < 100 m（楼内）| 100 Mbps–1 Gbps | 低 | 公寓楼、办公楼 |
| FTTC | 10–100 m | 100–250 Mbps | 中高 | 城市旧住宅区 |
| FTTN | 100–600 m | 25–100 Mbps | 中 | 复用旧铜线基础设施 |
| HFC | 同轴（共享）| 100 Mbps–1 Gbps | 低 | 已有 Cable TV 覆盖区域 |
| Fixed Wireless | 无线（几 km）| 25–75 Mbps | 中 | 郊区/农村 |
| LEO 卫星 | 无 | 50–200 Mbps | 高 | 极偏远地区 |

**选择原则：** 不是选最先进的，而是选**成本 / 性能 / 已有基础设施 / 可维护性**最平衡的组合。这也是澳洲 NBN 为什么混合使用多种技术的原因。

## 六、三种介质综合对比

| | 铜线 | 光纤 | 无线 |
|--|------|------|------|
| 频率上限 | ~几百 MHz | THz 级 | 取决于频段 |
| 典型带宽 | Mbps–Gbps | Tbps | Mbps–Gbps |
| 抗电磁干扰 | 差（天线效应）| 完全免疫 | 差（共享介质）|
| 传输距离 | DSL: < 4 km | SMF: 50–100 km | 取决于频率 |
| 安全性 | 较好（有线）| 很好 | 差（广播介质）|
| 部署成本 | 低（已有基础设施）| 高（施工精度高）| 中 |
| 维护 | 氧化、老化、串扰 | 弯曲、灰尘、接续难 | 受环境影响大 |
| 适合 Last Mile | DSL（短期利旧）| FTTP（长期投资）| 偏远区域 |

## 七、核心结论

1. **介质不是中性的。** 不同介质主动决定网络性能、成本和维护方式。
2. **铜线核心敌人：** 电阻损耗、趋肤效应、天线效应、串扰。差分信号 + 双绞是对抗手段。
3. **DSL 本质：** QAM + FDM + 大量子信道并行，而非单一频率传输。距离是性能的根本限制。
4. **光纤的强大来自：** THz 频段 + 全内反射 + 多波长复用（WDM/DWDM）。
5. **无线本质：** 低频远但慢，高频快但短。无线是共享广播介质，默认不安全。
6. **Last Mile 设计：** 不是选最快的技术，而是选总体最划算、最适合现有基础设施的组合。光纤越往前推，可用铜线段越短，速率越高——这是 FTTx 系列方案的核心逻辑。
