min frame time ≥ 2× one-way prop delay [碰撞窗口] (Eth=64B), else collision undetectable. CD backoff = binary exponential (0~2ⁿ-1), give up at 16.

Wireless [有线CD vs 无线CA]: hidden terminal (A/C unheard → collide at B) → RTS/CTS; exposed terminal (false busy). WiFi: per-frame ACK, no CD.

T5 HTTP / WEB

Methods GET/HEAD/POST. Status 2xx OK·3xx redirect·4xx client(404)·5xx server. Stateless → Cookie/Token [无状态]. 3rd-party cookie = cross-site tracking.

Perf: parallel (many TCP, costly) · persistent (1.1 reuse) · pipelining (HoL blocking) [队头阻塞]. Cache: ETag/If-None-Match, Last-Modified/If-Modified-Since (Conditional GET) [没变不传]. Proxy = cache-on-pull; CDN = push + DNS to nearest [拉vs推]. HTTP/3 = QUIC/UDP, kills TCP HoL.

T5 REALTIME

best-effort net, 3 problems: Latency (overall slow) / Jitter (variance ~15ms) / Loss. [到太晚=丢] equivalent loss = arrives past playout. Buffer: big=low-loss/high-delay, small=opposite.

Fixes: retransmit (slow, rare here) · elastic buffer · FEC (send redundancy R=P1⊕P2⊕P3 ahead) [带宽换延迟] · codec adapt. RTP (media, even port) / RTCP (feedback, odd port) / SIP (signalling) / DASH (HTTP adaptive).

T5 P2P / DHT

BitTorrent: piece 256/512KB, sub-piece 16KB; Rarest First [优先最稀有] + Random start + Endgame; Choking: re-eval 10s, optimistic unchoke 30s, ~4 concurrent; Tracker gives peers not files; SHA-1. Seeder ranks by upload rate.

DHT (replaces Tracker): ring, KeyID→nearest successor NodeID (160bit), finger table → O(log N) hops; replicate to pred/succ vs churn. exact lookup only, no wildcard/regex [结构锁死查询] (hash kills order) — same issue as MQTT wildcards.

⚠ EXAM TRAPS 最易错
  • BGP prepending → longer path → less preferred [方向别反] (for backup link). ≠ path injection (attack).
  • effective QoS = min(pub, sub) [取小]; MQTT is hop-by-hop, not e2e.
  • Fast Retransmit ≠ Fast Recovery: FR = when to resend (3 dup-ACK); FRecovery = no Slow Start, MD only. Tahoe has FR, no Fast Recovery; Reno has both [易混].
  • WIN (rcv buffer) ⟂ CWND (net estimate) [完全无关]. effective = min(W,WIN,CWND).
  • Counter equal = trustworthy; Gauge equal = NOT [计量陷阱]. Counter32 wraps at 4.29B; 10Gbps wraps ~3.4s → Counter64.
  • SNMP: agent = server, manager = client [反直觉].
  • Hierarchical routing "hop" unit changes [量纲变了]: routers → regions, 6>5 not worse.
  • Onion routing = telescoping [逐跳建链], not 3 keys at once; timing analysis defeats encryption.

Count-to-infinity (bad news travels slow) [坏消息慢] → Split Horizon / Poison Reverse. ECMP = equal-cost multipath (hash per flow). Hierarchical: aggregation shrinks tables, cost = suboptimal path [缩表换次优].

T6 BGP 域间·策略

Runs over TCP/179, manually configured peers, Path Vector (full AS path, not distance). AS Path: (1) loop detect — own ASN → drop; (2) policy scoring.

Prepending: repeat own ASN to look longer [更长=更不优] → steer to backup. eBGP (inter-AS): prepend ASN + rewrite next-hop at boundary. iBGP (intra-AS): sync external routes, full-mesh, iBGP-learned not re-advertised over iBGP; OSPF/IS-IS resolves next-hop.

Transit (paid, full reach) vs Peering (free, no transit) [付费vs互通]. Hot potato = dump early → asymmetric paths. Local-Pref = main outbound policy lever [出向主战场]. Control plane right→left vs data left→right [方向相反]. RIB→FIB. No native security (RPKI ~50%, BGPsec ≈0).

T7a CONGESTION / TCP

BDP = 2×BW×delay = in-flight data [在途数据]. 3 windows: W (sender, BDP) · WIN (rcv buffer) · CWND (net estimate), send = min(all). Congestion collapse: retx floods → goodput→0.

AIMD = additive-up (+1/RTT) · multiplicative-down (×0.5) [慢加快减] → sawtooth. Slow Start: CWND=1, double/RTT (actually exponential) [名字反了], loss → ssthresh=½ → AI.

T7c CRYPTO

4 properties: Confidentiality · Authentication (+ non-repudiation) · Integrity · Freshness (anti-replay).

Hybrid (=TLS): asymmetric opens, symmetric (AES-GCM) carries data [非对称开局]. Forward secrecy: ephemeral DH (g^ab, a/b discarded) → future key leak can't decrypt past [用完即扔]. Modes: ECB (never)/CBC (POODLE)/GCM (AEAD, modern) [首选].

PKI: CA signs X.509, ~88 root certs. Revocation broken (CRL won't scale) [撤销失效]. TLS sits between transport & app, handshake before first HTTP req [握手在前]; UDP = DTLS. Post-quantum: Shor breaks RSA/ECC, AES-256 OK if doubled.

DNSSEC (integrity + authenticity, NOT confidentiality) [不做机密]: RRSIG (signs RR set) · DNSKEY (KSK signs ZSK, ZSK signs records) · DS (parent → child KSK) · NSEC (leaks zone → NSEC3) [泄露zone]. Trust anchor = root key (hardcoded).

T7c ONION / WIFI-SEC

Onion (Tor): Guard (src not dst)/Middle/Exit (dst not src), telescoping per-hop key [逐跳建链], layered. Exit sees dst → still need app crypto. Timing analysis defeats layered encryption [时序防不住]. vs MPLS (pins whole path) = more fragile.
