# 本地模型 vs API：选型与成本

## 开源模型开源了什么

**开放的核心内容：**

- **模型权重（Weights）**：训练出来的参数文件（几 GB 到几百 GB），下载即可推理。Qwen2.5:7b 量化后约 4-5GB。
- **模型架构（Architecture）**：Transformer 的具体配置——层数、attention head 数、激活函数，通常以代码形式公开。
- **Tokenizer**：文本和 token 之间的映射表与算法。

**不一定给的：** 训练代码（有的给）、训练数据（大多不给）、RLHF / 对齐细节（一般不给）。

**"开源"其实是个光谱：** Llama 系列严格来说是"开放权重"（open weights），有商用许可限制。真正接近全开源的如 OLMo、Pythia，连训练数据都公开。

## 本地部署的成本

**硬件（大头）：**

| 场景 | 需求 |
|------|------|
| 7B 量化模型（Qwen2.5:7b、Llama 3.1:8b） | 8GB 显存消费级显卡，或 M 系列 Mac |
| 70B 模型 | 40-48GB 显存，A6000 或多卡，几万人民币起 |
| 云 GPU（RunPod、Vast.ai） | A100 约 $1-2/小时 |

**其他费用：**

- **电费**：消费级显卡满载 200-350W，7×24 跑满一个月约几十到一百多元
- **存储**：模型文件 + 向量数据库，普通 SSD 即可
- **工具调用的外部 API**：搜索（Serper ~$50/5万次）、邮件等该花还是要花
- **向量数据库**：本地 ChromaDB 免费，云服务（Pinecone）另计
- **部署**：给他人使用时的服务器、域名等常规成本

**核心优势：推理免费，不按 token 计费。** 代价是自己搞硬件和运维。在自己的 Mac 或带显卡的台式机上跑 7B 做开发实验，额外费用基本为零。瓶颈是显存和推理速度，不是钱。

## API 定价（2026 年 4 月）

按每百万 token（MTok）计费，输入/输出分开算。

**Anthropic Claude：**

| 模型 | 输入 | 输出 | 定位 |
|------|------|------|------|
| Haiku 4.5 | $1 | $5 | 快速、廉价、高吞吐 |
| Sonnet 4.6 | $3 | $15 | 性价比均衡 |
| Opus 4.6 | $5 | $25 | 最强推理 |

**OpenAI：**

| 模型 | 输入 | 输出 | 定位 |
|------|------|------|------|
| GPT-5.4 Nano | $0.20 | $1.25 | 超低成本 |
| GPT-5.4 Mini | $0.75 | $4.50 | 中端性价比 |
| GPT-5.4 Standard | $2.50 | $15 | 主力模型 |

标准定价下 OpenAI 各档位普遍更便宜，Nano 是 Anthropic 目前没有对标产品的超低价选项。

### 省钱手段

**Batch API**：异步处理，24 小时内返回，输入输出打五折。适合批量分类、数据处理、内容生成。

**Prompt Caching**：缓存命中的输入 token 打一折（省 90%）。agent 每次带相同 system prompt 和长上下文时效果显著。

两者叠加理论上最多省 95%。

### 实际费用估算

场景：每次交互 2000 输入 + 500 输出 token，每天 100 次。

| | Claude Sonnet 4.6 | GPT-5.4 Mini |
|---|---|---|
| 输入（6M token/月） | $18 | $4.5 |
| 输出（1.5M token/月） | $22.5 | $6.75 |
| **月费** | **~$40** | **~$11** |

不含 caching。若 system prompt 占输入 70% 且命中缓存，实际费用再减一半以上。

## 本地 vs API 对比

| | 本地开源 | Claude / OpenAI API |
|---|---|---|
| 推理成本 | 电费（几乎免费） | 按 token 计费 |
| 前期投入 | 显卡（几千到几万） | 零 |
| 模型质量 | 7B 明显弱于旗舰 | 旗舰水平 |
| 运维 | 自己搞 | 零 |
| 延迟 | 取决于硬件 | 通常更快 |
| 隐私 | 数据不出本地 | 数据发到第三方 |

**务实建议：** 开发阶段用 API（快、质量高、不用折腾环境）。等 agent 的 prompt 和工具链跑通、架构定型后，再评估是否值得迁移本地模型降成本。架构没定型就折腾本地部署是过早优化。
